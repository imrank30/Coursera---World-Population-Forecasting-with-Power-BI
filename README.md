# Coursera---World-Population-Forecasting-with-Power-BI
This project uses Microsoft Power BI to analyze and forecast global population trends from 1960 to 2021. It includes visualizations such as line charts, column charts, and maps, with a forecasting feature to predict population growth for the next 10 years.

What I Did

Added a line chart visualizing world population by year.
Applied Power BI's forecasting tool to predict population trends for the next 10 years.
Customized the forecast line color, transparency, and confidence bands for better visualization.
Incorporated other visuals such as continent-wise population column charts and country-level population maps to provide comprehensive insights.
Outcome

The report successfully displays historical population data alongside a forecasted trend, helping to understand potential future population growth. This exercise enhanced my skills in data visualization, report formatting, and predictive analytics using Power BI.
